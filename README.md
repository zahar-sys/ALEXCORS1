# Alexcors

Двухстраничный сайт магазина одежды в стиле Old Money.

## Открыть в VS Code

1. Распакуйте ZIP.
2. В VS Code выберите **File → Open Folder** и откройте папку **Alexcors**.
3. Откройте встроенный терминал (**Terminal → New Terminal**).
4. Запустите локальный сервер из папки проекта:

```bash
python3 -m http.server 5500
```

5. Перейдите в браузере на http://localhost:5500.

Можно также воспользоваться расширением VS Code **Live Server** и выбрать **Open with Live Server** для `index.html`.

Установка npm-пакетов и сборка не нужны. Для полной работы поиска и обновления адреса открывайте сайт через локальный сервер, а не через `file://`.

## Структура

- `index.html` — главная страница с заголовком «Добро пожаловать в Alexcors».
- `catalog.html` — каталог: 18 карточек, 5 категорий.
- `styles.css` — цвета, типографика, оформление и адаптация под телефон.
- `catalog.js` — фильтры, поиск, счётчик, пустое состояние.
- `assets/` — фотографии из присланных скриншотов и иконка сайта.

## Категории

- `jackets` — куртки, 5 карточек.
- `polos` — поло и трикотаж, 4 карточки.
- `trousers` — брюки, 3 карточки.
- `sets` — комплекты, 3 карточки.
- `shoes` — обувь, 3 карточки.

## Как редактировать товар

В `catalog.html` найдите нужный `<article class="product">`.

- `data-category` определяет категорию.
- `data-search` содержит текст для поиска: название, цвет и категорию.
- `<h2>` — название товара.
- `.product-description` — цвет или краткое описание.
- `.product-link` ведёт в Telegram-канал магазина.

Чтобы добавить вещь, скопируйте одну карточку и поменяйте эти поля. Счётчик JavaScript рассчитывается автоматически. При добавлении категории создайте кнопку с новым `data-filter` и используйте это же значение в `data-category` товаров.

## Фотографии

Исходные изображения — скриншоты с несколькими товарами. CSS-контейнер `.crop` показывает отдельную область каждого скриншота. Сами фотографии не перерисованы.

Для замены на отдельное фото товара замените содержимое `.product-photo` на:

```html
<img class="standalone-photo" src="assets/new-product.jpg" alt="Описание товара">
```

И добавьте в `styles.css`:

```css
.standalone-photo {
  width: 100%;
  height: 100%;
  object-fit: cover;
}
```

Для большей чёткости стоит заменить фрагменты скриншотов на оригинальные фотографии товаров.

## Важные детали

- Названия и цвета составлены по фотографиям. Цены, размеры и наличие не выдуманы: сайт предлагает уточнять их в Telegram.
- Ссылка магазина: https://t.me/AlexKorsStore.
- Это витрина: оплаты, корзины, аккаунтов и серверной базы данных нет.
- В архиве нет паролей, токенов или зависимости от ChatGPT. Его можно размещать на любом статическом хостинге.
